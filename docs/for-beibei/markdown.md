## 基础语法

### 标题

Markdown 中共有 **六级标题**，用 `#` 表示，一个 `#` 对应一级标题，由大到小排列。

> 举个例子 🌰
> 
> ```
> # 这是一级标题
> ## 这是二级标题
> ### 这是三级标题
> ...
> ```
> 


### 字体

- 文本用 `*` 包裹起来，一个 `*` 包裹表示 *斜体*，两个 `*` 包裹表示 **粗体**，三个 `*` 包裹表示 ***斜体加粗***。

- 文本用 `~~` 包裹起来表示 ~~删除~~，用 `<u></u>` 标签包裹起来表示 <u>下划线</u>，用 `<mark></mark>` 标签包裹起来表示 <mark>高亮</mark>。


### 分隔符

可以用连续的三个 `-` 表示分隔符，或者使用 `<hr />`。

文本的换行可以通过两种方式实现：**空行** 进行文本的换行；使用 `<br/>`。



### 列表

列表分为 **有序列表** 和 **无序列表** 两类。

- 无序列表用 `-`、`+`、`*` 开头，并用空格和内容隔开，控制列表层级可以在列表符号前使用Tab（缩进）。

> 🌰
> - 有序列表用 `-` 开头，并用空格和内容隔开。
>   - 无序列表
  
1. 有序列表用 `数字` 开头，并用空格和内容隔开，控制列表层级可以在列表符号前使用Tab。

> 🌰
> 1. 有序列表用 `数字` 开头，并用空格和内容隔开。<br />
>   1.1 有序列表


### 确认项

确认项已 `- [ ]` 开头，并用空格和内容隔开。`- [x]` 表示已完成。部分 Markdown 编辑器支持交互点击。

> 🌰
> - [ ] 未完成确认项
> - [x] 已完成确认项


### 表格

表格使用 `|` 作为 **字段** 分隔符，用 `-` 作为 **标题** 分隔符。

例如以下的写法会被渲染为表格。

```
|标题1｜标题2|
|-|-|
|WJL|ZZF|
|18|16|
```

|标题1|标题2|
|-|-|
|WJL|ZZF|
|18|16|

> 💡 如果需要对齐，可以在 **标题分隔符** 处用 `:` 表示对齐方式。
> 
> `:-` 表示左对齐；`-:` 表示右对齐；`:-:` 表示居中对齐。


### 链接

在 Markdown 中，链接采用 `[]()` 语法，其中 **方括号** 中填写页面展示文字，**圆括号** 中填写链接地址。

例如 `[百度](https://www.baidu.com)` 会被渲染为 [百度](https://www.baidu.com)


### 图片

在 Markdown 中，图片采用 `![]()` 语法，其中 **方括号** 中填写图片未加载出来的兜底文字，**圆括号** 中填写图片链接地址。

例如 `![Just Crazy](https://gw.alipayobjects.com/zos/bmw-prod/598d14af-4f1c-497d-b579-5ac42cd4dd1f/k7bjua9c_w132_h130.png)` 会被渲染成如下图片。

![Just Crazy](https://gw.alipayobjects.com/zos/bmw-prod/598d14af-4f1c-497d-b579-5ac42cd4dd1f/k7bjua9c_w132_h130.png)



## 高级语法

### 公式渲染

$$
E=mc^2
$$

### 代码块渲染

```python
def printName(name):
  printf('name is' name)
```


### 图片渲染

支持 **流程图**、**雷达图**、**Git图**、**类图**、**时序图**、**...** 等多种图标，支持类型详见 [mermaid](https://mermaid.nodejs.cn/)。

语法为简单的 *```* 包裹，头部表明解释器使用 **mermaid**。

<pre>
```mermaid
graph TD
A --> B
```
</pre>

```mermaid
graph TD
A --> B
```
